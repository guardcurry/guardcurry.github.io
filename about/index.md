你好，我是**徐奥**。这里是我的个人写作站点，用来存放散文与随笔。

## 关于这个站点

站点是纯静态的：内容写在 Markdown 里，由一个几十行的 PowerShell 脚本 `build.ps1` 渲染成 HTML，再托管在 GitHub Pages 上。没有数据库，没有后端，没有服务器费用。

- 写作：在 `blog/` 下新建 `日期-标题/index.md`，写好 YAML 头部和正文
- 生成：双击 `build.cmd`
- 发布：把改动上传到 GitHub，Pages 会自动更新
